# App-JokenPo

Um app de JokenPo feito em Kotlin no android studio, feito para aprendizado em sala de aula.

## 1. Introdução

O projeto consiste no desenvolvimento de um aplicativo de **Jokenpô (Pedra, Papel e Tesoura)** para dispositivos Android. O aplicativo foi desenvolvido utilizando **Kotlin** e **Android Studio**.

A ideia do projeto é criar um jogo simples e fácil de utilizar, no qual o jogador escolhe entre pedra, papel ou tesoura, e o aplicativo realiza uma escolha aleatória para competir contra o jogador.

## 2. Objetivo

O objetivo do aplicativo é permitir que o usuário jogue Jokenpô contra o computador de uma maneira simples e divertida.

O projeto também teve como objetivo colocar em prática conhecimentos básicos de programação e desenvolvimento de aplicativos Android.

## 3. Tecnologias utilizadas

* **Android Studio:** utilizado para desenvolver o aplicativo.
* **Kotlin:** linguagem utilizada para programar a lógica do jogo.
* **Android:** plataforma para a qual o aplicativo foi desenvolvido.

## 4. Funcionamento

Ao abrir o aplicativo, o jogador pode escolher uma das três opções:

* Pedra;
* Papel;
* Tesoura.

Depois da escolha do jogador, o computador escolhe uma opção aleatoriamente.

O aplicativo então compara as duas escolhas e mostra na tela quem venceu.

As regras utilizadas são:

* Pedra vence a Tesoura;
* Tesoura vence o Papel;
* Papel vence a Pedra;
* Quando os dois escolhem a mesma opção, ocorre um empate.

## 5. Interface

A interface foi desenvolvida de forma simples, para facilitar a utilização.

Na tela principal são apresentadas as opções de Pedra, Papel e Tesoura. Após o jogador realizar sua escolha, o aplicativo mostra a escolha do computador e o resultado da partida.

## 6. Conclusão

O desenvolvimento do aplicativo Jokenpô foi uma forma de colocar em prática conceitos básicos de programação e desenvolvimento Android.

Com o projeto, foi possível aprender mais sobre a linguagem Kotlin, o Android Studio, criação de interfaces e utilização de comandos para controlar as ações realizadas pelo usuário.

O resultado é um aplicativo simples, funcional e fácil de utilizar.
